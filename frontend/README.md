# Фронтенд: «Новостные инсайты» в Альфа-Бизнесе

React 18 + TypeScript + Vite, без UI-библиотек. Стили лежат в `src/styles.css`.

## Экраны

- **Главная Альфа-Бизнеса** (`/`): шапка, левое меню, тёмный блок с балансом (статика), ряд «Сводка».
- **Виджет «Инсайты для вашего бизнеса»** рядом с «Активными заявками» — точка входа в сервис. Показывает 3 самых релевантных события с меткой «Риск» / «Возможность» и кнопку «Все инсайты». Если агент событие ещё не разбирал, ставится метка «Новое».
- **Пункт меню «Новостные инсайты»** с плашкой НОВОЕ.
- **Переключатель компании** в шапке. При смене компании меняются виджет и лента.
- **Страница сервиса** (`/insights/:newsId`):
  - выбор роли (собственник, CEO, CFO, казначейство, главбух): от роли зависит разбор;
  - профиль компании: признаки из CSV, доля рынка, группа, все страны ВЭД, ключевые поставщики и покупатели по реальным платежам (доля в платежах и отрасль);
  - слева лента с фильтрами и причиной отбора («Почему в ленте…»);
  - справа карточка события из трёх цветных блоков: **факты** (синий), **позиция Альфа-Банка** (красный), **вывод AI** (фиолетовый). У каждого утверждения есть ссылка на источник, факт или признак клиента;
  - под карточкой — признаки компании, учтённые в выводе, и список источников с цитатами из аналитики банка;
  - **«Как получен вывод»** — шаги агента из `/insights/{id}/trace`;
  - **«Задать вопрос»** — чат по событию, `POST /insights/{id}/ask`.

Разбор строится при открытии события через `POST /companies/{id}/insights`. Бэкенд его кэширует, поэтому повторное открытие мгновенное. Пока агент работает, на экране видны его шаги. Ошибки LLM (например, нет ключа) показываются в карточке с кнопкой «Попробовать ещё раз».

## Запуск

Всё вместе, из корня репозитория:

```bash
docker compose up --build   # фронт: http://localhost:3000, API: http://localhost:8000/docs
```

Только фронт, для разработки:

```bash
cd frontend
cp .env.example .env
npm install
npm run dev                 # http://localhost:5173, /api проксируется на BACKEND_URL
```

`VITE_USE_MOCKS=true` включает демо-данные из `src/mocks`, бэкенд при этом не нужен. На всех экранах тогда висит полоса «Демо-данные», а виджет и карточки события помечены, чтобы на показе заготовленные примеры нельзя было спутать с ответами живого агента. Для показа жюри используйте режим без моков.

## Как устроен код

| Файл | Что делает |
|---|---|
| `src/api/backend.ts` | Форматы ответов FastAPI |
| `src/api/adapter.ts` | Приводит ответы к модели интерфейса (`src/api/types.ts`): источники `N*`/`A*`, признаки, трасса |
| `src/api/client.ts` | Запросы и переключение на моки |
| `src/config/companies.ts` | Какие компании показывать и как их называть. Компании в датасете обезличены, поэтому названия явно условные: «Клиент А · зерновой трейдер» |
| `scripts/export_companies.py` | Выгружает профили демо-клиентов из CSV для моков |
